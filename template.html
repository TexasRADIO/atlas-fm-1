FM-1 Firmware Atlas

You bought an M-VAVE FM-1. Dozens of people have rewritten its firmware since July 2026 and the pace is daily. This page is the map: a short path to get going safely, then every known firmware with what it tries to be, what sounds it ships, how it talks MIDI, whether the project is still alive, and where to install it from.

Start here

Six steps. Nothing here needs soldering or special hardware, just a USB data cable and Chrome or Edge.

Know what you have

The FM-1 is a JieLi AC791N with 1 MB flash, a 240x240 screen, USB MIDI, Bluetooth MIDI and a 3.5 mm TRS Type A MIDI input (input only). Stock firmware shows its version at power-on; V15 is current.

  • Linux/macOS: fm1_install.py --info from any Felucca-family repo prints the identity, e.g. FM-1_015.
  • Older than V15? Update first: M-VAVE downloads (Windows/macOS updater) or fm1-linux-update.

Decide what you want it to be

Stock is a 6-op DX7-style synth. The mods turn it into a groovebox, drum machine, Prophet-5, Juno-106, Omnichord, kalimba, sampler, or a MIDI controller. Jump to the purpose map and pick a direction before a name.

Check the project is alive

The Health column uses the repo's last push date: active within 14 days, quiet 15 to 60 days, stale older or removed. Stars show how many people have tried it. Prefer active projects with a web installer and a documented way back to stock.

Install from stock V15

  • Back up presets and projects first. Firmwares store data differently.
  • Community rule: go back to stock V15 before flashing a different custom firmware.
  • Open the project's web installer in Chrome or Edge, plug in by USB (no hub), press Install. About a minute.
  • Hashes: every GitHub release ships a .fwsc; check its SHA256 when provided.

If it goes wrong

  • Black screen, still on USB as 4c4a:8057: jl-uboot-tool or MvaveFM1Unbricker, no opening the case.
  • Felucca-family rescue: hold OCT- while powering on, then reinstall.
  • Nothing on USB at all: FM-1 Transporter (an RP2040 dongle) or Flipper Zero recovery.
  • Help: r/MVaveFM1.

MIDI, in one paragraph

Everything receives notes on USB and most on TRS. Stock and the Felucca family receive MIDI clock and follow Start/Stop; stock locks only after a Start arrives while the arp or sequencer runs. Only Baud Girl and Groove OS (both closed) can send clock. CTL-1 turns the FM-1 into a controller. Details per firmware are in the MIDI column.

Other directories (use them too)

This atlas does not host installers. These sites do, and each is maintained by someone in the scene.

fm1-editor.com/firmware

Catalog with version numbers, update dates, GitHub stars and install notes, sortable. Closest thing to this page; lacks purpose grouping and lineage.

thefirmwarehub.com

One-click browser installer for ~40 firmwares, checks repos nightly, has stock restore and a rescue script. Run by zvenson (sloopDX, zp12).

aroum/fm1-custom-fw

The most complete written directory (65+ firmwares, tools, reverse engineering, recovery). A long README; this atlas was seeded from it.

awesome-fm-1

Curated link list: official downloads, firmwares, patch tools, guides, videos, communities.

Hardware: JieLi AC791N (WL82), dual pi32v2 cores, 1 MB flash, 240x240 TFT, USB-MIDI, BLE MIDI, 3.5 mm TRS MIDI IN (Type A, input only). USB IDs: stock 4c4a:c755, Felucca family 1209:0001, UBOOT rescue 4c4a:8057.
